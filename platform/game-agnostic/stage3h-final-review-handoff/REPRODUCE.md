# Reproduce the handoff checks without running a game

1. Verify the archive SHA-256 against `bundle-record.json` received through the authorized channel. Verify all member hashes against `HANDOFF_MANIFEST.json` using the supplied `verify-bundle.py`. Hashes provide content identity, not reviewer identity or permission to execute anything.
2. Extract into a new disposable local folder. The original V2 documents and source archive are preserved under their repository-relative paths. Read `HANDOFF.md`, `INTERNAL_AUDIT.md` and the V2 `REVIEW_PACKET.md` before interpreting any validation result.
3. For a fresh source-package clone check, copy these four files from the extracted V2 directory into another disposable folder: `clean-clone-preflight.py`, `local-source-package.tar.gz`, `source-package-manifest.json`, `local-package-record.json`. Run `python3 clean-clone-preflight.py` there. It creates and deletes a temporary local package repository/clone, verifies source bytes, runs the existing synthetic tests and loads module definitions only. It does not construct a native game world or invoke policy/evaluator performance. Run no other native generator/evaluator/registration command.
4. Read the generated temporary `clean-clone-preflight.json`. Expected scope is `PASS_PACKAGE_CLONE_SYNTHETIC_ONLY`, 75 byte-verified files, 14 synthetic checks, zero native worlds and no independent-review assertion. Node/V8/Python/Git versions are supplied in the handoff runtime provenance; a different host must record its own identity and differences. Native canonical-numerics certification and resource/custody readiness remain pending.
5. Use `reviewer-response-template.json` only as a response template. Actual reviewer identity, expertise, conflicts, date and signed disposition must be supplied by the independent person; the author has filled none of them. Review acceptance must name the exact package/protocol/source/analysis/runtime targets and resolve required corrections.

`integrity-check.mjs` is the original-workspace integrity check and expects the protected local repository tree. It is not the standalone archive verifier or a campaign runner. The archive is an immutable review snapshot; run clone checks in disposable copies, not by changing its contents. Any scientific correction is a separately numbered prospective amendment after actual independent review, not an edit of this snapshot or V2.
