# Stage 2E-Z — Real-State Parity Expansion and Sustained Shadow Certification

Stage 2E-Z implements a fail-closed workflow for real ZekNova states. A capture contains a universal snapshot, incumbent Stage 1A-Z evidence from the exact same detached state, and coverage context. The evaluator compares observations, masks, targets, transitions, outcome, ranking, selection, legality, source-state immutability and R0 authority.

The default production profile requires 1,000 records, 250 distinct source states, five sessions, all four factions and biomes, 12 missions, multiple operating bands, six legal masks, 320,000 simulations, exact parity and zero legality, mutation or authority violations.

The cumulative kernel certifies the machinery with replay captures. Real sustained-shadow certification remains pending until Desktop runtime captures satisfy the profile.
