## Deployable boundary

DEPLOYABLE_ACTION_MODEL_V1 accepts only the current observable state, visible map, and ACTION_SEMANTICS_V1. It applies E1 effects in an action-effect projection, marks unavailable quantities UNKNOWN, and explicitly leaves all actual successor health, entity positions/service, resource state, terminal state and legality UNKNOWN. PROTECT's certified shield flag and COLLECT's certified service removal are projected; RESTORE service is EU, never treated as E1. TRANSFER delivery uses the inherited declaration and is audited separately. UNKNOWN effects are never resolved using simulator truth.

Depth d means root action + d continuation steps. The deployable bounded search enumerates a MOVE/WAIT navigation envelope on the named t0 reference map, with continuation legality and survival UNKNOWN. The outputs are conditional planning descriptors, not forecasts of actual legal successor worlds. At each depth, a fixed linear scorer uses the root observable features plus the deterministic envelope descriptors. Root candidates are the frozen zero-cost policy surface. Subsequent target actions with unavailable legality are not invented. Limitations of this restricted continuation surface are disclosed: the known/deployable gap includes search-surface, value-access and capacity differences and cannot establish forecasting need by itself.
